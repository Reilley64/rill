# Numeric addresses, owned TCP directions and explicit network control

[#34](https://github.com/Reilley64/rill/issues/34) defines `std::net` as the v0 TCP/address/system-host-resolution foundation. The user explicitly confirmed consolidated Q1-Q92 and Q93's binding-based mutability clarification. The [networking contract](../networking-contracts.md) is authoritative; [prototype 25](../../prototypes/25-networking.rill) and its [independent inventory](../prototypes/25-networking.md) are hand-checked design evidence, not an implemented library, Rill execution, native acceptance, security/safety proof or accepted RFC.

## Value identity is not resolution or connection identity

Use nominal private-representation IPv4/IPv6 values and socket endpoints with explicit `u16` ports and IPv6 `u32` scopes. Pure strict parsers/canonical renderers never call DNS or map interfaces. Family/address/port/scope determine equality/hash; IPv4 and mapped IPv6 stay distinct. Scoped text is a numeric endpoint grammar, not URI percent decoding. The separate native name-to-scope operation is a point-in-time local observation, not ownership of an interface.

System resolution accepts the documented ASCII lookup-name subset, preserves caller case/root-dot semantics, returns owned scoped endpoints, and does not authenticate the caller's intended service name. Reject numeric-looking legacy forms at that boundary rather than pretend `getaddrinfo` has a hostname-only flag. Reuse system sources/order/caching without adding a bespoke DNS client, IDNA policy, hidden mapped synthesis or a new cache. These deliberate restrictions trade arbitrary OS database keys and legacy literal convenience for a portable, inspectable input boundary.

## Ownership and native release are separate from outcomes

Whole TCP streams/listeners are genuine noncopyable owned resources. Reuse canonical `std::io` read/write/flush/consuming-close and exact `IoFailure<NetError>` prefixes. Raw transport is unbuffered; flush does not test health or acknowledge delivery. Consuming split creates one owned direction of the same connection per half, not a clonable descriptor or general TLS parallelism promise. Public reunite/raw-handle constructors and live option mutation are omitted.

Raw write-half close/disposal attempts local send-direction release even when the read half survives. This **explicit TCP-specific refinement** does not flush a discarded `BufferedWriter` queue, perform TLS/application shutdown, or join the other half's routine. Preserve safe shared native state until the actual last owner/use releases it. Consuming close relinquishes the public owner after success or ordinary failure; an error/abort request alone never proves callback/buffer quiescence or licenses retrying a recycled descriptor.

## Control is explicit, borrowed and non-destructive

`NetControl` carries a clock borrow, optional absolute instant and token borrow. It and configuration records use ordinary public fields: #15 has no per-field mutability modifiers. Mutable bindings/exclusive access edit caller values, while operations and controlled views capture stable value snapshots retaining all ordinary dependencies. A copied descriptor is not `noBorrow` or an owned clock/token copy, and caller descriptor edits do not retarget admitted work.

`ControlledTcp<S>` borrows the existing resource and implements the appropriate canonical I/O capabilities without taking close ownership. Ordinary token/deadline/clock failure may return typed network errors and final actual prefixes, including effects committed during required cleanup; intrinsic routine cancellation remains outside `Result`. Never destroy a borrowed resource merely to abort controlled I/O. Wait if nondestructive abortion cannot confirm release. No rollback, pristine protocol state or hard return-time guarantee follows.

Q81 explicitly adds identity-only `std::time::checkInstantDomain` to the [clock contract](../clock-cancellation-contracts.md). The concurrently approved SQL amendment names the same operation `validateInstantDomain`; both names preserve one canonical identity rather than duplicate validators. It permits domain preflight before token observation without reading time or exposing private IDs. Keep basic/domain validation, already-requested-token handling, clock/expiry checks and admission ordered. After admission, ready ties are unspecified; preserve one selected outcome through cleanup. `withDeadline` still preserves nested results, not a hidden generic cancellation adapter.

Hostname dialing deliberately resolves a complete system batch before family-interleaved attempts; it is not full RFC 8305 incremental-DNS conformance. At most two attempts are live, including cleanup; 250 ms spacing and a default ten-second attempt cap are policy, not return-latency bounds. The caller's single absolute deadline covers lookup/all attempts. Start eligibility, available slots, terminal selection and completed cleanup are different conditions. Hold the chosen winner while joining losers; do not invent failed unstarted candidates or replace success because cleanup crossed the deadline.

## Deliberate support and failure boundaries

Live v0 networking targets native Linux/macOS. Pure address APIs remain portable and networking names/types remain present on `wasm32-wasip1`; otherwise-valid live requests fail typed `Unsupported` rather than require custom imports, inherited-socket handoff or a silent preview2 upgrade. UDP/Unix/raw/general DNS records, provider/FFI selection and TLS/HTTP/SQL semantics remain outside this decision.

Defaults are explicit: IPv6-only listeners, backlog 128 as an OS-capped hint, reuse off, NODELAY on, keepalive off and linger disabled. Applicable requested settings must take effect or fail before resource publication; local SIGPIPE suppression does not alter process-global signal policy. Report native operation resource shortages as documented `NetError` data without making Rill/runtime allocation failure recoverable. A peer may already have seen effects before setup/control failure; typed errors are not external transactions.

The [primary-source research](../research/0034-tcp-dns-platform-and-cancellation.md) records platform/version limits, not a chosen poller/resolver/provider or proof. All real-native rows in prototype 25's inventory are **NOT RUN**. #28 still owes complete checking, dependency/evidence, control-commit/progress, bounded cleanup and error-translation rules; #30 retains pinned target/ABI/Wasm/backend gates. Actual descriptor reuse, option support, clock registration, native quiescence and late-progress accounting must be demonstrated. An unworkable required mechanism returns to map #1 rather than silently weakening the contract or dropping a target.
