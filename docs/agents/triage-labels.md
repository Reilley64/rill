# Triage labels

Use these canonical labels unchanged.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide information. |
| `ready-for-agent` | The work is specified for an autonomous agent. |
| `ready-for-human` | A human needs to implement the work. |
| `wontfix` | The project does not plan to act on it. |
