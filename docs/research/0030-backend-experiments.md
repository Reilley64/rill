All tail cases verify call counts and results, not merely survival. The sret buffer is owned by the still-live root ordinary caller; tail callees forward that earlier storage. Native probe IR has no heap activation allocation; assembly contains direct sibling branches/indirect branch transfers (O2 may replace some self cycles with loops). Wasm WAT retains direct/indirect `return_call` where required. The async sampler completes before each transfer; continuation finalizers balance callbacks before the next one. Constant-size counters avoid retaining one sample per call. None of these observations proves every temporary peak, engine allocation, signature or arbitrary chain length.

## Why the prior pipeline cannot clear the gate

1. **Proper-tail + Asyncify is still incompatible.** LLVM can emit valid Wasm return calls using a supported convention, and Wasmtime can execute them with its own host fibers, but stock Asyncify rejects them. Replacing return calls with ordinary calls is not a fix: the ordinary control saves 476 / 3,612 / 28,700 bytes at depths 16 / 128 / 1,024. That is a control demonstrating retained ordinary history, not a proposed lowering.
2. **Managed-region containment is independently missing.** The saved-region test corrupts neighboring in-bounds storage before trapping; the leaf red-zone test corrupts neighboring storage without trapping. Overall memory bounds and checking only stack-pointer assignments do not satisfy #22. Additional accounting/checks must cover frames, padding, arguments, return buffers, runtime/native entry and saved pushes before writes, with checked arithmetic. Guard pages and host limits do not supply that mechanism.
3. **The ABI is not uniformly established.** AArch64's incoming-byval rejection is concrete. Passing scalar, small-aggregate and explicit-return-buffer candidates does not authorize a silent signature exception or ordinary-call fallback. A complete Rill ABI/lifetime explanation remains necessary.
4. **A host-specific positive result is not a portable architecture decision.** Wasmtime async fibers retain native frames rather than Asyncify's serialized state. Correctly charging all retained activation storage against Rill's separate managed saved budget, and the intended WASIp1/browser/embedding deployment scope, remain unresolved. One configured 1 MiB host fiber is not that accounting proof.
5. **Runtime obligations are not implemented by the harness.** No compiler exists here to generate masks, protected cleanup, remaining-field actions, source eligibility checks, native leases or M:N scheduling. The copying control is a valid retention mechanism for its bytes, not implementation of all borrowed results/zero-copy/native adapters or same-store concurrent growth. Models explicitly preserve their declared ordering/pending-state rules, not an unimplemented language runtime.
