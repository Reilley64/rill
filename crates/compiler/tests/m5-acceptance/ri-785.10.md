This is ticket B5, the closeout audit of the ri-785 slice (#71, callable captures and erased evidence) under [RFC 0007](../../../../docs/rfcs/0007-ownership-borrowing-mutation-and-cleanup.md). It changes no compiler source, test, cap or expectation. Every row below is an existing test, run unchanged. All outcomes are compiler judgments over MIR (or typed receipts, where stated). No Rill program ran; the value `12` of RFC case O15 is not observed (M6).
