# ri-px1 closeout audit (ri-px1.10, 2026-11-23)

This is ticket D5, the closeout audit of the ri-px1 slice (#72, ordered cleanup and protected obligations) under [RFC 0007](../../../../docs/rfcs/0007-ownership-borrowing-mutation-and-cleanup.md). It replays obligations K1 to K8 of §1.4 of the M5 gap analysis, in both installed load modes, at the integration tip `8dfcb008` (B5, ri-785.10). It changes no compiler source, test, cap or expectation. Every row below is an existing test, run unchanged. No row is red. Each row is green, or green with a limit that a named bead owns, or deferred to a named bead. Three limits need the reader's eye: K1's O19 witness, K2's graph root for a written field disposal, and K3's O20 and O21. They are the first three entries under "Limits".

All outcomes are compiler judgments over MIR (or typed receipts, where stated). No Rill program ran, and no provider or scheduler delivered anything (M6).
