# M5 per-ticket evidence

Each M5 ticket writes its evidence here, in one new file named after its ticket bead, such as `ri-785.4.md`. These files continue the [M5 evidence ledger](../m5-acceptance.md): read them with it.

One file per ticket keeps tickets from editing the same lines, so their branches merge without conflicts. Edit only your own ticket's file. To correct another ticket's record, add a dated section to your own file that names it.

Start the file with a heading that names the ticket and its date, then state:

- what the ticket changed, and the commits;
- each test it added or changed, and the result;
- every cap it pinned, exact and one short, and any fixed cap it left unchanged;
- what it did not establish.
