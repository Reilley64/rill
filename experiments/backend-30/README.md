## Reproduce

Recorded host: macOS 27.0.1 (26A434), Darwin 27, Apple M3/AArch64. Python 3.9.6; assert-enabled C builds. Do not use `python -O` or define `NDEBUG`.

Required local tools: Homebrew LLVM **23.1.5** (`clang`, `opt`, `llc`), separate LLD **23.1.5** (`wasm-ld`), Xcode/macOS SDK, Node **26.13.0**. Rust is inventoried but does not build this harness. `--fetch-tools` downloads official Binaryen **133** and Wasmtime **50.0.1** macOS/ARM CLI/C API release archives, verifies their pinned SHA-256 digests before extraction, and installs nothing globally.

```sh
python3 experiments/backend-30/run.py \
  --fetch-tools \
  --llvm /opt/homebrew/opt/llvm/bin \
  --linker /opt/homebrew/bin/wasm-ld \
  --tools /tmp/rill-backend-30-tools \
  --out /tmp/rill-30-reproduction
```

To include the other recorded binary targets, add `--extended-targets`. This needs **already installed Rosetta** and an **already running Docker daemon** with Linux/ARM64 and Linux/AMD64 execution. The runner does not install Rosetta or start Docker. It uses immutable official Rust/Debian-based image digests; Docker may download missing images. Containers have no network and are removed on completion. Only this directory (read-only) and the chosen output directory are mounted. No existing container, image tag or volume is changed/deleted. Linux helper C is compiled with the image's GCC; the actual tail/ABI functions are still cross-generated by LLVM 23.1.5 on macOS.

```sh
python3 experiments/backend-30/run.py \
  --extended-targets --out /tmp/rill-30-all-targets
```

The recorded execution used the second form. Fresh reproduction requires available disk space for the pinned images. macOS x86-64 runs through Rosetta; Linux x86-64 through the Docker VM's translation/emulation. They are runtime observations, **not physical x86-64 hardware validation**.

## Files and outputs

- `run.py`: valid IR generation, verification, O0/O2 optimization/codegen, link/transform/execute commands, immutable tool/image pins and evidence collection. LLVM verifier success does not establish every lifetime promise; see the audit. The root-owned return buffer remains live through its ordinary call; only the internal forwarding chain is mandatory-tail.
- `native.c`: constant-size SP sampler, results/count checks, explicitly mapped 1 MiB pthread stack with guards outside it. This is not Rill's usable-capacity accounting or M:N stack scheduler.
- `wasmtime.c`: Cranelift async-host candidate with observed custom fixed fiber allocations and continuation finalization; relocating-growth/copy/foreign-worker retention control; isolated engine-overflow instance. No outer-driver same-store access while a call future is alive.
- `asyncify.mjs`: ordinary-recursion saved-history control and **expected contract failures** for saved-buffer and LLVM leaf-red-zone containment. Caught traps are external embedding observations, never a Rill catchable-overflow API.
- `cleanup.c`: explicit ordered worklist/cause-like rendering and checked arena arithmetic **models**. Cancellation/suspending callback completion are modeled transitions, not Rill masking/native-join implementation. Worklist allocation failure aborts a separate process, never recurses as fallback.
- `evidence/results.json`, `evidence/commands.json`: recorded machine-readable observations, hashes, commands and exit codes. The report describes raw-log publication. The output directory also contains complete stdout/stderr, generated IR, assembly, objects, executables and Wasm/WAT; **binaries and downloaded tools are not checked in**.

`run.py` exits zero only when the *expected experimental observations* reproduce. This includes deliberate compile rejections, fatal injected allocation failures and two canary-corruption counterexamples. **Zero does not mean all contracts pass.** Explicit `contract: FAIL` observations and the `gate: OPEN` result must not be hidden by a green shell exit.

## Negative source eligibility inventory

Only the first row has a lowered live-local control here; the other source-rule cases remain **awaiting a Rill compiler/checker**. They are not invalid mandatory-tail IR tests.

| Final-looking source situation | Required lowering/evidence |
| --- | --- |
| Callee borrows a caller local, or caller accesses it after the call | Ordinary call; retain the local/frame. `ordinary_control` observes a live slot before and after recursion. No local pointer is passed through a mandatory-tail transfer. |
| Pending guard disposal/protected resource release | Ordinary call with disposal afterward; never release early just to obtain TCO. Worklist model is not this source classification test. |
| Scoped child or native borrower still requires join | Ordinary call; retain backing and join to completion/confirmed abortion before release. Owner/cancel request is not that completion. |
| Explicit error wrapping after call | Ordinary call with wrapper construction afterward. Unchanged #29 propagation does not automatically add trace/cleanup work and must be considered independently. |

Unsupported lowering of a genuinely eligible call must reject, not silently use any of these ordinary-call exceptions. Complete Rill ABI/checker classification, automatic generated admission and production runtime/provider acceptance remain unimplemented.
